# Locket

一个本地优先的密码管理器 MVP。保险库在浏览器中使用 Web Crypto 加密后写入 IndexedDB，不依赖后端，也不会上传主密码或条目内容。

## 功能

- 主密码创建与解锁
- AES-256-GCM 加密
- PBKDF2-SHA256 密钥派生（310,000 次迭代）
- 登录、银行卡、安全笔记与 Wi-Fi 分类
- 搜索、收藏、密码生成与复制
- 5 分钟无操作自动锁定
- 加密备份导入与导出

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

生产构建和检查：

```bash
npm run build
npm test
```

## 安全边界

这是可用的产品原型，并非经过独立安全审计的正式密码管理器。主密码无法恢复；上线保存真实高价值凭据前，应完成专业密码学审计、依赖审计和浏览器威胁模型评审。
